# CI Integration

stackprice can be added to any GitHub Actions workflow to
automatically estimate infrastructure costs on pull requests.
No additional services or accounts required — just AWS
credentials and stackprice.

## Basic Setup

Add a workflow file at `.github/workflows/cost.yml` in your
CDK repository:

```yaml
name: Cost Estimate

on:
  pull_request:

jobs:
  cost:
    runs-on: ubuntu-latest
    permissions:
      pull-requests: write

    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: 20

      - name: Install dependencies
        run: npm install

      - name: Install stackprice
        run: npm install -g stackprice

      - name: Synthesize CDK
        run: npx cdk synth
        env:
          AWS_ACCESS_KEY_ID: ${{ secrets.AWS_ACCESS_KEY_ID }}
          AWS_SECRET_ACCESS_KEY: ${{ secrets.AWS_SECRET_ACCESS_KEY }}
          AWS_DEFAULT_REGION: us-east-1

      - name: Estimate cost
        run: |
          stackprice breakdown \
            --dir ./cdk.out \
            --output json \
            --out-file estimate.json
        env:
          AWS_ACCESS_KEY_ID: ${{ secrets.AWS_ACCESS_KEY_ID }}
          AWS_SECRET_ACCESS_KEY: ${{ secrets.AWS_SECRET_ACCESS_KEY }}

      - name: Post PR comment
        uses: actions/github-script@v7
        with:
          script: |
            const fs = require('fs');
            const estimate = JSON.parse(
              fs.readFileSync('estimate.json', 'utf8')
            );

            const fixed = estimate.stacks
              .flatMap(s => s.resources)
              .map(r => `| ${r.logicalId} | ${r.type} | $${r.monthlyCost.toFixed(2)} |`)
              .join('\n');

            const usageBased = estimate.stacks
              .flatMap(s => s.usageBasedResources)
              .map(r => `| ${r.logicalId} | ${r.type} | usage-based |`)
              .join('\n');

            const total = estimate.totalMonthlyCost.toFixed(2);

            const body = [
              '## 💰 stackprice estimate',
              '',
              '| Resource | Type | Monthly Cost |',
              '|---|---|---|',
              fixed,
              usageBased,
              '',
              `**Total: $${total}/month + usage-based**`,
              '',
              `_Generated by [stackprice](https://github.com/suneelsristi/stackprice) v${estimate.stackpriceVersion}_`
            ].filter(Boolean).join('\n');

            github.rest.issues.createComment({
              issue_number: context.issue.number,
              owner: context.repo.owner,
              repo: context.repo.repo,
              body
            });
```

## Cost Diff on PRs

To show cost changes between the base branch and the PR branch,
use `stackprice diff`. This requires generating a breakdown
from both the base and PR branch:

```yaml
name: Cost Diff

on:
  pull_request:

jobs:
  cost-diff:
    runs-on: ubuntu-latest
    permissions:
      pull-requests: write

    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - uses: actions/setup-node@v4
        with:
          node-version: 20

      - name: Install dependencies
        run: npm install

      - name: Install stackprice
        run: npm install -g stackprice

      - name: Synthesize PR branch
        run: npx cdk synth --output cdk.out.after
        env:
          AWS_ACCESS_KEY_ID: ${{ secrets.AWS_ACCESS_KEY_ID }}
          AWS_SECRET_ACCESS_KEY: ${{ secrets.AWS_SECRET_ACCESS_KEY }}
          AWS_DEFAULT_REGION: us-east-1

      - name: Get base branch cost
        run: |
          git checkout ${{ github.base_ref }}
          npm install
          npx cdk synth --output cdk.out.before
        env:
          AWS_ACCESS_KEY_ID: ${{ secrets.AWS_ACCESS_KEY_ID }}
          AWS_SECRET_ACCESS_KEY: ${{ secrets.AWS_SECRET_ACCESS_KEY }}
          AWS_DEFAULT_REGION: us-east-1

      - name: Generate estimates
        run: |
          stackprice breakdown \
            --dir ./cdk.out.before \
            --output json \
            --out-file before.json
          stackprice breakdown \
            --dir ./cdk.out.after \
            --output json \
            --out-file after.json
        env:
          AWS_ACCESS_KEY_ID: ${{ secrets.AWS_ACCESS_KEY_ID }}
          AWS_SECRET_ACCESS_KEY: ${{ secrets.AWS_SECRET_ACCESS_KEY }}

      - name: Run diff
        run: |
          stackprice diff before.json after.json \
            --format json \
            --out-file diff.json

      - name: Post diff comment
        uses: actions/github-script@v7
        with:
          script: |
            const fs = require('fs');
            const diff = JSON.parse(
              fs.readFileSync('diff.json', 'utf8')
            );

            const changed = diff.resources
              .filter(r => r.kind !== 'unchanged')
              .map(r => {
                const before = r.beforeCost != null
                  ? `$${r.beforeCost.toFixed(2)}` : '—';
                const after = r.afterCost != null
                  ? `$${r.afterCost.toFixed(2)}` : '—';
                const delta = r.delta != null
                  ? (r.delta >= 0
                      ? `+$${r.delta.toFixed(2)}`
                      : `-$${Math.abs(r.delta).toFixed(2)}`)
                  : 'usage-based';
                return `| ${r.logicalId} | ${r.type} | ${before} | ${after} | ${delta} |`;
              })
              .join('\n');

            const s = diff.summary;
            const deltaSign = s.delta >= 0 ? '+' : '-';
            const deltaStr = `${deltaSign}$${Math.abs(s.delta).toFixed(2)}/month`;

            const body = [
              '## 💰 stackprice cost diff',
              '',
              `**${deltaStr}** · ${s.added} added · ${s.removed} removed · ${s.changed} changed · ${s.unchanged} unchanged`,
              '',
              changed.length > 0 ? '| Resource | Type | Before | After | Delta |' : '',
              changed.length > 0 ? '|---|---|---|---|---|' : '',
              changed,
              '',
              `_Generated by [stackprice](https://github.com/suneelsristi/stackprice)_`
            ].filter(Boolean).join('\n');

            github.rest.issues.createComment({
              issue_number: context.issue.number,
              owner: context.repo.owner,
              repo: context.repo.repo,
              body
            });
```

## AWS Credentials Setup

Both workflows require AWS credentials with the
`pricing:GetProducts` permission stored as repository secrets:

1. Go to your repository → Settings → Secrets and variables
   → Actions → New repository secret
2. Add `AWS_ACCESS_KEY_ID` and `AWS_SECRET_ACCESS_KEY`

The minimum IAM permission required:

```json
{
  "Effect": "Allow",
  "Action": ["pricing:GetProducts"],
  "Resource": "*"
}
```

## Notes

- stackprice does not make any changes to your AWS infrastructure
- All pricing data is fetched from the AWS Price List API
- Results are cached locally for 24 hours — use --no-cache
  to force fresh pricing data
- Usage-based resources (Lambda, S3, SQS, SNS) show unit
  prices only — actual cost depends on usage
